Wi-Fi 本地审计工作台 · Windows x64 / RTX 5080
版本：2026-10-29

工作流程：StickS3 采集自家 Wi-Fi 握手 → 台式机导入 → 中文界面配置候选 → Hashcat 计算。

快速开始
1. 完整解压到本地可写目录，例如 D:\WiFiAudit。
2. 准备支持 RTX 5080 的 NVIDIA 驱动及匹配的 CUDA Toolkit 12.8 或更新版。
3. 双击「启动工作台.cmd」。无需另装 Python。
4. 在「工具与设备」检查 GPU，运行人工样本，确认计算正确。
5. 如需直接导入 .pcap，按「Windows使用说明.md」安装 WSL / hcxtools。
   已转换的 .hc22000 文件可直接导入，不需要 WSL。

包含
- Windows Python 运行环境、Hashcat 8.0.0、离线拼音库。
- 中文原文、全拼、首字母、大小写、年份和自定义数字/符号组合。
- 本地 UTF-8 字典、ASCII 规则变形、通用 PCFG 概率生成、格式枚举。
- 分阶段时间预算、任务队列、检查点恢复、本地结果查看。

先阅读「Windows使用说明.md」。研究比较见「方案调研.md」，验证范围见「新版验证记录.txt」。
源码和测试都在本文件夹中；第三方许可见「工具来源与许可.md」及各组件目录。

数据只写到本机 local-data 文件夹。计算时保留启动窗口；退出前暂停任务并等待保存。
暂停恢复可能重算未保存的批次。未找到口令不代表密码无法破解，只表示当前测试范围没有命中。
PCFG 是 Hashcat 通用模型，并非专门为中文密码训练。中文候选上限仅限制本地生成文件，
不限制 PCFG 或格式枚举的搜索空间；它们受各阶段时间预算约束。

验证说明
已在 Mac 上完成实际 Hashcat/hcxtools 与界面验证；Windows/WSL 路径有模拟测试。
尚未在你的 Windows / RTX 5080 上运行，不把 Mac 结果当作 5080 性能或兼容性实测。
