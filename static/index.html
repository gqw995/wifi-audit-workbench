COMPUTE ENVIRONMENT

工具与设备

Windows 使用完整的 Hashcat 8 目录。RTX 5080 需要匹配的 NVIDIA 驱动和支持 Blackwell 的 CUDA Toolkit。

本机工具

没有本地转换器时，通过 WSL 内的 hcxtools 转换；计算仍在 Windows 原生 GPU 上进行。直接导入 .hc22000 无需转换器。

验证 GPU

先检查是否识别到 RTX 5080 和 CUDA，再运行 WPA2 基准。速度以这台电脑的实测为准。
